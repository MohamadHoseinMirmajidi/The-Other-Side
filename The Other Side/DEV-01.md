# راهنمای سادهٔ تسک اول

پروژه را با Unity 6000.5.5f1 باز کنید. نسخهٔ بسته‌ها در Packages/manifest.json و Packages/packages-lock.json ثبت شده است؛ برای کار تیمی هر دو فایل را نگه دارید.

## صحنه

صحنهٔ اصلی: Assets/Project/Scene/Main.unity

در Hierarchy چهار آبجکت اصلی داریم:

- Main Camera: دوربین Orthographic با Size برابر 9.5؛ فعلاً کل نقشه را نشان می‌دهد.
- Global Light 2D: نور عمومی صحنه.
- Environment: چهار بخش شماره‌گذاری‌شدهٔ محیط، پس‌زمینه و مرزهای چپ و راست.
- Player: شخصیت موقت با Rigidbody2D و BoxCollider2D؛ Body و Facing Marker فقط ظاهر آن هستند.

داخل هر بخش Environment، زمین، پس‌زمینه و وسایل مربوط به همان بخش قرار دارند. رنگ‌ها فقط برای جداکردن بخش‌ها هستند و آرت نهایی محسوب نمی‌شوند.

زمین و مرزهای چپ و راست Collider دارند. وسایل موقت فعلاً مانع عبور نیستند؛ رفتار چرخ‌دستی، پنل و در در تسک‌های مربوط به خودشان اضافه می‌شود. Player با جاذبه روی زمین می‌ایستد و چرخش Z آن قفل است. حرکت بازیکن متعلق به DEV-02 است.

## ویرایش دستی

برای جابه‌جایی یا تغییر اندازه، آبجکت را انتخاب کنید و Position یا Scale را در Inspector تغییر دهید. برای رنگ، Color در Sprite Renderer را تغییر دهید. تمام شکل‌ها از یک تصویر مربع سفید استفاده می‌کنند.

Sorting Layers به ترتیب Background، Shadow، Props، Player، Foreground و UI هستند. این‌ها ترتیب رسم تصویر را تعیین می‌کنند و با Layer مربوط به برخوردها تفاوت دارند.

پوشه‌های موجود Scene و Script با همان نام اولیه حفظ شده‌اند. Art برای تصویرها، Audio برای صدا، Prefabs برای آبجکت‌های قابل‌استفادهٔ مجدد و UI برای رابط کاربری است. فایل‌های .gitkeep فقط پوشه‌های خالی را در Git نگه می‌دارند.

## تست و خروجی

Main را باز کنید و Play بزنید. چهار بخش باید دیده شوند و Player روی زمین باقی بماند. فعلاً دکمه‌های حرکت کاری نمی‌کنند.

در File > Build Profiles، پلتفرم Windows و صحنهٔ Main را انتخاب کنید. خروجی آزمایشی در Builds/Windows-Basic ذخیره می‌شود. قاب مرجع 1920×1080 است. پوشهٔ Builds وارد Git نمی‌شود.

این نسخه اسکریپت اختصاصی یا منوی سفارشی ندارد. تنظیمات و آبجکت‌ها مستقیماً در Unity قابل‌ویرایش‌اند.
